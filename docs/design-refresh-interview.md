# デザイン刷新 (3Blue1Brown 風) のインタビュー記録

クラウドセッションで行ったインタビューの途中経過。ローカルセッションでこの続きから進める。

## 現状のデザインの性質

- `template/src/ui.tsx` の部品 (`Scene` / `Box` / `Flow` / `Code` / `FileTree`) は「見出し + 箱と矢印のスライド」の作り
- シーン間は `fade` のクロスフェードで切り替わり、要素は `usePop` / `useFadeIn` で現れるだけ
- 品質チェックは各シーン最後の静止画を Claude が読む方式で、動きそのものは検証していない

3Blue1Brown の洗練は、配色やフォントよりも動きの文法による部分が大きいという見立て:

- 同じ物体がシーンをまたいで残り、変形・移動して次の概念になる (カットやフェードがほぼない)
- 画面には常に 1 つのアイデアだけがあり、見出しや説明文の帯がない
- 図形が「描かれる」(線のストローク描画、文字の書き出し、トランスフォーム)
- 語りと動きがフレーム単位で同期している

## 決まったこと

- **目指す深さは未定。** 次の 3 段階を、実際に作って見比べて決める
  1. 見た目の統一: 配色・タイポグラフィ・余白・図形のトーン
  2. 描画の質感: スライド構成は残し、線の描画・文字の書き出し・要素の移動などのアニメーションの質を上げる
  3. 動きの文法: 物体がシーンをまたいで残り、変形しながら話が進む。見出しや字幕帯をなくす (`ui.tsx` と `assemble` の作り直しが必要)
- **既定を「音声あり」に変える。** 字幕モードで他の人に使ってもらったとき「音声はできないのか」と聞かれ、音声ありが期待値だと分かったため。字幕モードは選択肢として残す
- **エンジン (Remotion のまま / Manim に移行) は見比べてから決める。** Claude の推奨は Remotion のまま (中身はコード・ファイル構成・処理の流れが中心で、Manim の強みである数式・グラフが活きる場面が少ない。既存の組み立て・ナレーション同期・チェックの仕組みを活かせる)
- **見比べは 2 段階で行う**
  1. 「処理の流れ」のシーン 1 つで、Remotion の 3 段階と Manim 版を作り、深さとエンジンを決める
  2. 決めた方式で残りの 3 種類 (コードの解説・全体構成・設計の「なぜ」) を作り、苦手な種類がないか確かめる
- **題材は `aijnek/ocr_human_review_skill`。** 以前この題材で動画を 5 本作った。作業ディレクトリ (原稿・`.tsx`・ナレーション音声) は Mac の `~/.cache/onboarding-video/ocr_human_review_skill*/` にあり、旧版との直接比較に使える
- **サンプルの書き出しと TTS は Mac で行う** (Qwen3-TTS / MLX は Apple Silicon でしか動かないため)
